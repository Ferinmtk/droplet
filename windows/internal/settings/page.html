Windows

droplet changes nothing in Windows' startup or Explorer until you turn it on here. Like any installed app, it adds itself to the Start menu, which is also what lets its notifications show. droplet uninstall removes everything it added.
All set. droplet is running in the tray (look by the clock, under ^ if it's hidden). Right-click it to send files, send the clipboard or ring a device. In Explorer, right-click any file → Send to → droplet → …. You can close this tab.
